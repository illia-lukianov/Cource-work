# Usage Examples

## Login Example

Use the login form to authenticate with email and password.

## Session Restore Example

When the app restarts, it automatically restores the previous session if available.

## Role-Based Access Example

- Admin users can access the dashboard.
- Regular users are routed to the public home page.

## Error Handling Example

If a saved session is invalid, the app clears the localStorage entry and returns to the login page.
